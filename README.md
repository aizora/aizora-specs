# Aizora Specs

Это «конституция» блокчейна Aizora: здесь живут правила, параметры и улучшения (AIP).

## Идея названия
Aizora = AI (интеллект) + ora (свет, ясность).  
Мы строим блокчейн, где логика прозрачна, а архитектура продумана заранее.

## Текущая версия
v0.1 — MVP-спецификация.

## Где смотреть правила
- `PROTOCOL.md` — базовые параметры и отличия от биткоина.
- `AIP/` — папка с улучшениями (Aizora Improvement Proposals).
